# Simplex Method Desktop App

A desktop application built with:

- React (Frontend)
- FastAPI (Backend)
- Electron (Container)

## Setup instructions

1. Install dependencies in root: `npm install`
2. Set up Python backend:
   ```bash
   cd backend
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. Run the development environment:
   ```bash
   npm run dev
   ```
